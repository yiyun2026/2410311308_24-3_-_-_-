## 系统概况

技术栈为 Python 3.12 + Flask 3.1 + SQLite 3，采用表现层、业务逻辑层、数据访问层三层结构，浏览器访问。

实现的功能对应实验一的需求清单：

- 学生档案管理：基本信息、入学成绩、家庭成员、职务信息的录入、查询、修改、删除，支持批量导入与档案打印
- 成绩管理：初始化、输入、显示、删除、查找、插入、追加、保存、读入、计算、拷贝、排序、索引、分类统计、退出共 15 项操作，另有导出 CSV 与成绩状态流转
- 综合查询统计：按课程、班级两个维度汇总人数、平均分、最高分、最低分、及格率与分数段分布
- 用户与权限管理：添加用户、删除用户、修改密码，按管理员、教师、学生三种角色控制权限
- 数据备份与恢复：手工备份、从备份点恢复、备份日志

## 运行方式

```bash
cd src
pip install flask
python init_demo.py      # 首次运行，建库并写入演示数据
python app.py            # 启动服务
```

浏览器访问 http://127.0.0.1:5000
